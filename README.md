# レトロドライブ

ひろしさんのための、見て過ごすドライブ風景です。80年代のアーケードを思わせるドット絵で、赤い車の後ろからカメラが追い、道なりに景色が流れていきます。スコアもクラッシュもありません。開いたままにしておけます。

この一式は未公開のプレビューです。公開用のリポジトリ作成や GitHub Pages の有効化はしていません。そちらは、ひろしさんが別に決めてから進めてください。相対パスだけなので、あとから静的サイトに置くことはできます。ただしホスト側の設定は環境ごとに手作業が残ります。

## 開き方

`index.html` をブラウザにドロップするか、ダブルクリックします。ネットワークもビルドも不要です。ファイルのままで動きます。

同梱の `manifest.webmanifest` と `icon-180.png` / `icon-192.png` / `icon-512.png` は、あとで静的配信やホーム画面追加をするとき用です。`file://` で開いているあいだはマニフェストを読みにいきません。

## 景色

自動の道のりでは、およそ 1 分前後ずつ、次の順で移ります。境目は走りながら色と路肩のものが入れ替わります。

1. 森（朝もやと木漏れ日）
2. 砂漠
3. 海岸通り
4. 高層ビルの街（夕暮れ）
5. 田舎町
6. 山道

右上の「設定」から、速さ、道のり（自動または一つの景色）、時刻（自動 / 朝 / 昼 / 夕 / 夜）、ハンドル（まかせる / 自分で）、走査線、一時停止、全画面、音を変えられます。設定はしばらくすると隠れます。

ハンドルを「自分で」にすると、左右キーまたは画面の左右の端で車線を動けます。はなすと中央に戻ります。壁にはぶつかりません。

## 音

最初は音なしです。`AudioContext` は「音：なし」を「音：あり」にするまで作りません。エンジンと風の低い音だけです。音量は設定に残りますが、音のオンはページを開き直すたびにオフから始まります。

## 設定の保存

速さ、道のり、時刻、ハンドル、走査線、音量は `localStorage`（キー `retrodrive.prefs.v1`）に書きます。`file://` では保存できないブラウザがあるので、失敗してもそのまま走ります。

## 操作

- Space … 一時停止 / つづける
- F … 全画面
- 左右 または A / D … 自分でハンドルのときだけ
